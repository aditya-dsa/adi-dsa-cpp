Start the program.



Read the number of substations V.



Create an adjacency list using a vector of size V + 1.



Read the number of power lines E.



Repeat the following steps for each power line:
- Read two substations u and v.
- Add v to the adjacency list of u.
- Add u to the adjacency list of v.



Display the graph representation:
- Traverse each substation from 1 to V.
- Print all its connected substations.



Calculate the degree of each substation:
- Find the size of its adjacency list.
- Display the degree.



Stop the program.
