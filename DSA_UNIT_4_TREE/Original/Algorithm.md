Create a binary tree with root node 1.

Insert nodes 4 and 5 as the left and right children of node 2.



Create an inorder() function using a stack.



Initialize current to the root node.



Repeat while current is not NULL or the stack is not empty:
- Push the current node into the stack.
- Move to its left child.
- Pop the top node from the stack.
- Print its data.
